# OC-Project11-Architecture

Dépôt d'architecture du Projet 11 « Faites adhérer les parties prenantes avec un POC ».

## Object

Ce dépôt regroupe les documents d'architecture produits dans le cadre de la preuve de concept ainsi que les documents de référence fournis pour le projet.

L'objectif est de conserver une traçabilité complète des décisions architecturales ayant conduit à la réalisation de la preuve de concept, depuis l'analyse des exigences jusqu'à la préparation de l'industrialisation.

## Structure du dépôt

### references

Contient les documents de référence utilisés pour la conception de la preuve de concept :

- Déclaration des travaux d'architecture
- Document de définition de l'architecture
- Données de référence sur les spécialités NHS
- Exigences pour le développement de la PoC

### architecture

Contient les livrables d'architecture produits pour la preuve de concept :

- Architecture applicative de la preuve de concept
- Contrats REST de la preuve de concept
- Événements métier de la preuve de concept
- Architecture GitHub de la preuve de concept
- GitHub Actions de la preuve de concept

## Démarche retenue

La conception a été réalisée selon la séquence suivante :

Exigences

→ Architecture cible

→ Microservices candidats

→ Contrats REST

→ Événements métier

→ GitHub

→ GitHub Actions

→ Implémentation de la preuve de concept

## Statut

Ce dépôt constitue la référence documentaire utilisée pour la conception, l'industrialisation, l'implémentation et la validation de la preuve de concept.
